### v1.0.9

- Shows a notice on the `Home` tab when a newer version of the plugin is available
- Fixes a crash when exporting the base artboard as SVG
- Fixes SVG images that looked stretched or mis-sized when artwork extended past the edge of the artboard
- Removes the `html_output_extension` setting, since `.svelte` is now the only output format

### v1.0.8

- Trims whitespace from `:png`/`:png24` layer exports, which makes the images much smaller
- Fixes a bug when exporting `:svg` layers

### v1.0.7

- Fixes MRAP errors that popped up when exporting SVG in newer versions of Illustrator

### v1.0.6

- Reworks the IDs and classes assigned to tagged layers
- Shows the correct identifier for tagged text layers in the plugin
- Applies `transform-origin: center` to all transform-based animations

### v1.0.5

- Fixes a bug that loaded every image regardless of viewport size when `include_resizer_css` was enabled
- Replaces the `respect_height` setting with `fit_mode`, whose `width`, `height` and `cover` options give more control over how the graphic fits its parent container

### v1.0.4

- Detects unsaved changes more reliably when switching between documents
- Improves event handling performance
- Fixes styles being lost or mixed up across documents
- Fixes text frames nested inside groups rendering incorrectly
- Fixes spaces being dropped after bold or italic text in the same text frame

### v1.0.3

- Fixes alpha channel values in shadow colors
- Remembers your unsaved settings when you switch documents
- Refactors the codebase for easier maintenance
- Renames the PecorinoII shadow to Pecorino2 to fix a serialization issue
- Keeps text objects in the same stacking order as in Illustrator
- Improves how animations are defined in the exported Svelte component
- Adds support for `*:text` and `*:htext` tagged text layers
- Fixes `*:png24` tagged layers not exporting correctly
- Fixes `*:svg` tagged layers not exporting correctly
- Adds blend mode support to `*:svg`, `*:png` and `*:png24` tagged layers
- Adds the `respect_height`, `override_text` and `allow_overflow` settings

### v1.0.2

- Fixes default settings for first-time users
- Sets `width: 100%` on the base div, so graphics scale correctly inside flex or grid parents
- Exports tagged layers to a dedicated folder, so files with the same name no longer clash
- Warns you when your plugin is older than the version the file was created with
- Allows images to be embedded inside `:svg` layers
- Adds the `priority_fetch` setting for loading critical above-the-fold images first

### v1.0.1

- Fixes minor onboarding issues for first-time users

### v1.0.0

A ground-up redesign of ai2svelte, with changes to both what it can do and how you use it.

#### Interface and workflow

- **Panel interface**: ai2svelte is now a visual panel instead of a script you run
- **Simpler workflow**: common tasks take fewer steps and are easier to find

#### Design and styling

- **Shadows and animations**: a built-in library of preset shadows and animations
- **Layer order**: exported layers now match Illustrator's stacking order
- **Tighter SVGs**: SVG layers are cropped to their content instead of the full artboard

#### New features

- **Snippets**: place interactive elements inside your Illustrator artwork
- **Batched exports**: export several Svelte files from one Illustrator document
- **Style editor**: write SCSS directly in the ai2svelte panel
- **Priority image fetching**: set `priority_fetch: true` to load critical above-the-fold images first
- **Profiles**: save and load export settings for different projects or workflows
- **Templates**: create and reuse templates for consistent project structure and styling
- **Font mapping**: map Illustrator fonts to CSS font stacks
