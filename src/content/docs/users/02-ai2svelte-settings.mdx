ai2svelte starts new panel projects with a bundled profile combined with the engine defaults. The values below show the effective factory defaults; the bundled profile overrides the engine defaults for image format, output paths, image source path, and inline SVG. You can change any of them in the `Settings` tab of the ai2svelte panel.

The [ai2svelte settings reference](../ai2svelte-settings-reference/) explains what each setting does.

Boolean values are shown as `true` or `false`; the engine also accepts the legacy `yes` and `no` forms.

```yaml
namespace: g-
image_format: webp
write_image_files: true
responsiveness: dynamic
text_responsiveness: dynamic
output: one-file
html_output_path: ../src/lib/ai2svelte/
image_output_path: ../src/statics/images/graphics/
image_source_path: images/graphics/
png_transparent: true
png_number_of_colors: 256
image_quality: 90
center_html_output: true
use_2x_images_if_possible: true
include_resizer_widths: true
include_resizer_css: true
inline_svg: true
use_lazy_loader: false
svg_embed_images: false
render_text_as: html
render_rotated_skewed_text_as: html
testing_mode: false
show_completion_dialog_box: true
priority_fetch: false
fit_mode: width
override_text: false
allow_overflow: false
```

Other settings inherit their engine defaults. In particular, `max_width`, `image_alt_text`, `clickable_link`, and `svg_id_prefix` are blank, while `project_name` defaults to the Illustrator file name.

### Adding and removing settings

<Steps>
  1. Open the `Settings` tab in the ai2svelte panel. {/* prettier-ignore */}
  2. Switch from `UI` to `Code` format view. {/* prettier-ignore */}
  3. Add or delete settings as YAML key-value pairs.
  {/* prettier-ignore */}
</Steps>

The code editor highlights syntax and suggests valid values as you type.

### Saving custom defaults

To make your current settings the new default, scroll to the bottom of the `Settings` tab and click `Save Profile`. Enter `default` as the profile name and click `OK`. Your settings are saved to the `default` profile, which every new project then starts from.

### Restoring default settings

To undo your changes, scroll to the bottom of the `Settings` tab and click `Reset Config`. This restores the settings stored in the `default` profile. If you've saved your own `default` profile, you get those settings back, not the factory defaults.
