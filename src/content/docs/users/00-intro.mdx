**ai2svelte** is Reuters Graphics' adaptation of [ai2html](http://ai2html.org/), the open-source script originally built at The New York Times.

It exports Adobe Illustrator artwork as clean, responsive Svelte components that you can drop straight into a web app.

---

### Installation

Download the latest `.zxp` file from the releases page, then install it with ZXP Installer.

<CardGrid>
  <LinkCard
    title="ZXP Installer"
    href="https://aescripts.com/learn/zxp-installer/"
  />
  <LinkCard
    title="Latest Releases"
    href="https://github.com/reuters-graphics/ai2svelte/releases/"
  />
</CardGrid>

After installing, open the plugin from `Window` > `Extensions` in Illustrator.

<Aside>
  If Illustrator was open during installation, restart it to load the plugin.
</Aside>
