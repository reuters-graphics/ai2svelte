ai2svelte lets you style any Illustrator object with a CSS selector. Objects you've named become CSS IDs automatically. Objects with default names (like `<Rectangle>`) have to be targeted by hand.

If you install AiHostAdapter, Adobe's helper plugin for CEP extensions, ai2svelte can detect selectors for you. AiHostAdapter passes Illustrator's selection events to the panel.

### Installing AiHostAdapter

<LinkCard
  title="Adobe Github"
  href="https://github.com/Adobe-CEP/CEP-Resources/tree/master/CEP_11.x/AIHostAdapter"
/>

{/* prettier-ignore */}
<Steps>
  1. Download the latest AiHostAdapter from Adobe's GitHub repository.
  2. Copy the `.aip` file into Illustrator's plug-ins folder:
     - Windows: `C:\Program Files\Adobe\Adobe Illustrator <version>\Plug-ins\Extensions`
     - macOS: `/Applications/Adobe Illustrator <version>/Plug-ins.localized/`
  3. Restart Illustrator.
</Steps>

To check that it works, open the `Styles` tab and select a named object in your document. Its selector should appear in the `Identifier` field.
