## Troubleshooting

<details>
<summary>Why doesn't the Identifier field update when I select objects?</summary>

If the `Identifier` field in the ai2svelte panel doesn't change when you select objects in Illustrator, AiHostAdapter probably isn't installed correctly.

**Solution:** Check that `AiHostAdapter.aip` is in the right folder. See the [Auto-detect selectors guide](../auto-detect/) for installation steps.

</details>

<details>
<summary>Why does the Identifier show the parent layer instead of the object I selected?</summary>

When a layer contains only one object, Illustrator treats the object and its layer as the same thing.

**Solution:**
Put more than one object in the layer so Illustrator can tell them apart. Give every object you want to style its own name.

</details>

<details>
<summary>How do I export an artboard that's wider than its breakpoint?</summary>

By default, ai2svelte uses each artboard's width in Illustrator as its breakpoint.

**Solution:**
Use an [artboard tag](../tagged-layers/#artboard-tags) to set the breakpoint yourself. For example, a 2000px-wide artboard tagged `:1200` becomes visible at 1200px. Also set `allow_overflow: true` so the artwork isn't clipped, and `include_resizer_css: false` so Svelte's window size bindings pick the artboard instead of container queries.

</details>

<details>
<summary>Why doesn't backdrop capture work on my computer?</summary>

Backdrop capture only works on macOS, because it relies on macOS screen capture APIs.

**Solution:**
On macOS, give Illustrator permission to record the screen: open **System Settings > Privacy & Security > Screen & System Audio Recording** and turn on Adobe Illustrator.

</details>

<details>
<summary>Which platforms are supported?</summary>

ai2svelte runs on Windows and macOS, but it hasn't been tested on Windows yet. Contributions to improve Windows support are welcome.

</details>

## Layer organization

<details>
<summary>Why can't I style objects in untagged layers?</summary>

ai2svelte only exposes objects in tagged layers for styling. Everything in untagged layers is flattened into the background image, so you can't target individual objects.

**Solution:** Move the objects you want to style into a tagged layer:

- **`:svg`** for vector artwork you want to scale and style with CSS
- **`:png`** or **`:png24`** for raster images and complex artwork that should stay an image

</details>

<details>
<summary>Do I need a separate tagged layer for each artboard?</summary>

**No.** One tagged layer can span several artboards, which keeps your document simpler.

**Best practices:**

- Use one tagged layer that covers every artboard you export
- Arrange objects inside the layer so they're easy to find
- Name the objects you want to style

</details>

<details>
<summary>How do I add data attributes to an object?</summary>

Select the object, open `Window → Attributes`, and type `key: value` pairs in the note field, one per line. ai2svelte turns each pair into a `data-*` attribute, so `category: road` becomes `data-category="road"`.

Commas and semicolons also separate pairs, so wrap a value in double quotes when it needs one: `tags: "road, bridge"` becomes `data-tags="road, bridge"`. Quotes are optional otherwise.

Notes work on text, objects in `:div`, `:symbol`, `:snippet`, `:svg` and `:png`/`:png24` layers.

See [Data attributes](../data-attributes/) for more.

</details>

## Performance

<details>
<summary>How do I make an above-the-fold graphic load faster?</summary>

You can tell the browser to load the graphic's images before other resources.

**Solution:** Add `priority_fetch: true` to your ai2svelte settings:

```yaml
# ... other settings
priority_fetch: true
```

**⚠️ Important:** Only use `priority_fetch` for graphics readers see straight away. If you use it too often, those images compete with other important resources and the page can load more slowly overall.

**Best for:** hero images and key visuals that are on screen when the page loads.

</details>
