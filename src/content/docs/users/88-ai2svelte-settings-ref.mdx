This page lists every ai2svelte export setting, what it does and which values it accepts.

---

### allow_overflow :badge[New]

If `true`, content can spill outside the ai2svelte container instead of being clipped.

Options: `false`, `true`

### alt_text

Sets the `aria-describedby` text on the ai2svelte container, so screen readers can describe the graphic.

Default: _(blank)_

### aria_role

Sets the ARIA `role` of the ai2svelte container, which tells assistive technologies what the graphic is.

Default: _(blank)_

### center_html_output

If `true`, centers the ai2svelte div inside its container.

Options: `true`, `false`

### clickable_link

Wraps the whole graphic in an `<a>` tag that links to the URL you enter.

Default: _(blank)_

### fit_mode :badge[New]

Sets which dimension of the parent element the graphic fits to. `width` fits the parent's width. `height` fits the parent's height instead. `cover` keeps the graphic's aspect ratio and fills the whole parent, cropping the graphic if the aspect ratios differ.

Options: `width`, `height`, `cover`

:::caution
With `height` or `cover`, the parent element must have a set width and height. Without a set height, results can be unpredictable.
:::

### html_output_path

The folder the Svelte components are written to, relative to the Illustrator file.

Default: `../src/lib/ai2svelte/`

### image_alt_text

Sets the alt text for the images in the exported component. To describe the whole graphic, use `alt_text`.

Default: _(blank)_

### image_format

The format of images exported from Illustrator. Pick one based on the quality and file size you need.

Options: `auto`, `png`, `png24`, `jpg`, `svg`

### image_output_path

The folder image files are written to, relative to the Illustrator file.

Default: `../src/statics/images/graphics/`

### image_source_path

The path `<img>` tags load images from. If blank, `image_output_path` is used. This doesn't change where the files are saved.

Default: `images/graphics/`

### include_resizer_css

If `true`, container queries decide which artboard is shown. If `false`, Svelte's window size bindings decide.

Options: `true`, `false`

### include_resizer_widths

Adds `data-min-width` and `data-max-width` attributes to the artboard containers.

Options: `true`, `false`

### inline_svg

If `true`, SVG markup is written into the Svelte component instead of being loaded from a separate file.

Options: `true`, `false`

:::caution
Blend modes are lost when `inline_svg` is `true`. Use it only for simple graphics.
:::

### jpg_quality

The quality of exported JPG images.

Options: any integer from 0 to 100

### max_width

Adds a `max-width` in pixels to cap the width of the output.

Options: any positive integer

### namespace

A prefix added to the HTML elements' names.

Options: any string  
Default: `g-`

### output

Whether to export everything into one file or several files.

Options: `one-file`, `multiple-files`

### override_text :badge[New]

If `true`, the text in `*:text` and `*:htext` layers is always taken from the `taggedText` prop.

Options: `false`, `true`

### png_number_of_colors

The number of colors in PNG and PNG24 images. Fewer colors give smaller files.

Options: any integer from 2 to 256

### png_transparent

Makes PNG backgrounds transparent. This can lower image quality; `image_format: png24` gives better results.

Options: `yes`, `no`

### priority_fetch :badge[New]

If `true`, the graphic's images load first. Use it for graphics that readers see straight away, such as hero images.

Options: `false`, `true`

:::caution
Use this only for above-the-fold graphics. It can hold up other resources on the page.
:::

### project_name

Overrides the project name, which is otherwise the Illustrator file name. Exported component and image files are named after it.

Options: any string  
Default: `[ai file name]`

### render_rotated_skewed_text_as

How rotated or skewed text is exported.

Options: `html`, `image`

### render_text_as

How text from Illustrator is exported in the Svelte component.

Options: `html`, `image`

### responsiveness

Whether the ai2svelte container resizes with its parent (`dynamic`) or keeps the artboard's size (`fixed`).

Options: `dynamic`, `fixed`

### show_completion_dialog_box

If `true`, shows a summary dialog when the export finishes.

Options: `true`, `false`

### svg_embed_images

Embeds images inside SVGs as base64.

Options: `false`, `true`

:::caution
Exports take longer. Use it only for very small images.
:::

### svg_id_prefix

A prefix added to SVG IDs so they don't clash with other IDs on the page.

Default: _(blank)_

### testing_mode

If `yes`, renders text both in the image and in the Svelte component, so you can check that text lines up.

Options: `no`, `yes`

### text_responsiveness

Whether HTML text from Illustrator area text keeps a fixed width or resizes with the graphic.

Options: `dynamic`, `fixed`

### use_2x_images_if_possible

If `yes`, exports images at double resolution when size limits allow.

Options: `yes`, `no`

### use_lazy_loader

Lazy-loads images, which speeds up the first load on pages with many or large images.

Options: `true`, `false`

### write_image_files

Whether to export artboards as image files.

Options: `yes`, `no`
