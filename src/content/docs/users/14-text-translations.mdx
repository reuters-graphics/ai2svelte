Need a French version of a graphic? Translate each text object once in the Text tab, then choose a language in the exported component to render a particular language. Translations are stored in the Illustrator document itself.

## Add languages

In the Text tab, select "Preview language" and choose **Manage languages** to add a new target language. Use a BCP 47 language tag such as `fr`, `fr-CA` or `zh-Hant-TW`. English (`en`) is the default source language; change it if your Illustrator text is in another language.

The exported component defaults to the source language. When a configured non-source language is selected, text without a saved translation renders blank. Changing the source language changes the declaration, not the text, so review existing translations afterward. Removing a language also deletes its translations.

## Translate the text

For finding and editing repeated text across artboards, see [Batch edit text](../text-editing/). Open a text card, choose a target in **Language**, enter the translation and select **Save translation**. One translation is used for every copy in the group.

For how to preserve inline styles while editing, see [Batch edit text](../text-editing/). Choose **Clear translation** to remove the translation for that language. If you change the source wording or formatting in Illustrator, make sure you change the translation as well. It's suggested to review all translations after making source changes.

## Preview a language

Choose a target language in **Preview language** to see it on the Illustrator canvas. The preview is a temporary copy of a saved `.ai` document; pending changes are saved before it opens. Text without a translation stays in the source language (for the preview only) and is marked red and underlined making it easy to identify missing translations.

You can still edit and save translations in the extension. Saving updates the original document and refreshes the preview. Canvas edits to the temporary copy are discarded when you switch languages, save translations or leave the Text tab. Choose **Source** in the picker or **Return to original** to close it. Export is unavailable during preview.

The preview uses Illustrator's text layout, so it may differ from the exported component. Long translations can overflow their text boxes. Threaded or noneditable text cannot be previewed; unlock and show it first. The preview renders texts in the default language font and the export will still use the font specified for the target language. However, the preview notes the CSS declaration for the target language font that you can use to set custom font for the target language in your component.

## Use translations in your component

With multiple languages configured, set the component's `lang` prop to switch languages:

```svelte
<Graphic lang="fr-CA" />
```

ai2svelte uses an exact configured tag when possible, then a configured base language, then the source. If that resolves to the source language, the original text is shown; a missing translation for a configured non-source language renders blank. A `lang` value with no configured exact or base language continues to resolve to the source language. For example, fr-CA uses fr-CA if configured, falls back to fr if only that is configured, and otherwise resolves to the source language.

Translations keep the source text's font and inline styles. For a language that needs a different font, add CSS in the Styles tab. The component sets `lang` on its root and translated paragraphs:

```scss
.ai2svelte [lang="hi"] {
  font-family: "Noto Sans Devanagari", sans-serif;
}

// or

#g-big-map-box [lang="hi"] {
  font-family: "Noto Sans Devanagari", sans-serif;
}
```

When the document has multiple languages, the `include_translations` setting defaults to `true`. Set it to `false` to export source text only; `lang` still labels the component but does not change its text. Text in raster or SVG output, `taggedText` overrides, snippets and custom HTML is not translated.
