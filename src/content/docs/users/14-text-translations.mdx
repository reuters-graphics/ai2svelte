The Text tab can store manual translations in an Illustrator document and include them in exported Svelte components. Translation data is document-specific; it is not part of a user profile. The default Text list shows repeated text across artboards. Turn on **Show all text** to include singletons and text that only occurs on one artboard.

## Set up languages

Open **Manage** in the Text tab to add canonical BCP 47 language tags such as `fr`, `fr-CA`, or `zh-Hant-TW`, and select the language the Illustrator text is written in. English (`en`) is the default source language. A document always has one source language and at least one configured language.

Removing the source language requires you to choose its replacement, or add a new language first. Changing the source language changes only the document's language declaration; it does not rewrite Illustrator text. Existing translations need review after a source-language change. Removing a target language removes it from the configured language list but retains its saved text in the document.

Save an untitled Illustrator document before adding languages or saving translations. Text editing and translation saving do not alter artwork unless you use **Apply** in the Source text mode.

## Edit translations

Choose a text card, switch to **Translations**, select one target language, and enter its translation. Drafts remain when switching targets in the dialog. Numbered style marks can be applied to selected text with the style chips; malformed or unavailable marks must be corrected before saving. Use **Clear translation** to remove the current target's saved value.

Translations are shared by all copies represented by a text card. If the Illustrator source text or its inline-style pattern changes, its prior translation is kept as an unmatched record rather than guessed onto the changed text. Review the current source before translating it again, or explicitly reassign an unmatched record and review it. Review means confirming that the translation still corresponds to the current source; it does not edit the artwork.

The component keeps the original text's layout and styling. A translation can be longer than its text box. It may not fit. Arbitrary paragraph-style remapping, font downloading, per-occurrence translation overrides, and translation of snippets or custom HTML/JavaScript are not supported. Text rendered as raster or SVG, and text controlled by a `taggedText` override, stays in the source language; the exporter warns when a saved translation cannot be applied there.

## Use the exported component

With more than one document language, the component exposes a reactive `lang` prop, for example `<Graphic lang="fr-CA" />`. It defaults to the document's source language. An exact configured tag is preferred; otherwise a configured base language is used, then the source. When a translation is missing or stale, the original Illustrator text and its formatting are shown.

The `include_translations` export setting defaults to `true` and appears in Settings when the document has multiple languages. Set it to `false` to export original source text only. In that mode there is no embedded translation dictionary or translation lookup logic. The `lang` prop still labels the component, but changing it does not translate text.

Translations are stored as structured text and style segments, not HTML. The extension escapes text through Svelte's normal text rendering. Source and translation strings are not interpreted as markup.
