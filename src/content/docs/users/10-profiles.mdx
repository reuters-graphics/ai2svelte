A profile is a saved set of ai2svelte settings. If your projects need different settings, save a profile for each and switch between them instead of changing options one by one.

### Sharing profiles

You can share profiles with teammates or move them to another machine, so everyone exports with the same settings.

To export your profiles, open the `Settings` tab, click `Save Profile` and choose `Export my profiles`. This creates a `profiles.json` file you can send to others.

To import profiles someone sent you, open the `Settings` tab, click `Load Profile` and choose `Import from file`. The imported profiles are saved locally, and you can pick any of them from the `Load Profile` dropdown.

### Default profile

The plugin comes with a profile named `default` that holds the recommended settings. To change it, load `default` from the `Load Profile` dropdown, edit the settings, then save it again with `Save Profile`.

From then on, `Reset Config` restores your `default` profile instead of the factory settings.
