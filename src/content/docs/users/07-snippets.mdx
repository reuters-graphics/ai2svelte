A snippet is a tagged layer that marks a placeholder in your artwork. When you use the generated Svelte component, you fill that placeholder with any content you like: video, charts, 3D, interactive widgets.

---

### Creating snippets

Create a layer in Illustrator and add `:snippet` to the end of its name. The part before the tag becomes a prop on the generated Svelte component.

For example, a layer named `video:snippet` creates a `video` prop. Pass it a Svelte snippet when you use the component:

```svelte
<script>
  import MyGraphic from './ai2svelte/my-graphic.svelte';

  import { assets } from '$app/paths';
</script>

<!-- Svelte snippet that renders an HTML video element -->
{#snippet videoSnippet()}
  <video
    style="width: 100%; height: 100%; object-fit: cover;"
    src={`${assets}/videos/video.mp4`}
    autoplay
    playsinline
    muted
    loop
  ></video>
{/snippet}

<!-- Pass the snippet to the video prop generated by ai2svelte -->
<MyGraphic assetsPath={assets} video={videoSnippet} />
```

A document can have as many snippet layers as you need. Each one becomes its own prop:

```svelte
<MyGraphic assetsPath={assets} video={videoSnippet} headline={headlineSnippet} />
```

Keep a snippet's objects in the same layer across all artboards. Otherwise ai2svelte creates a separate snippet for each one.

### Reusing a snippet

Several snippets often share the same markup and differ only in one value, such as the video file. As of Svelte 5.38, you can't pass a snippet with parameters as a prop, so you'd end up duplicating code.

Instead, use Svelte's [createRawSnippet](https://svelte.dev/docs/svelte/svelte#createRawSnippet) to build snippets that share a body but take different arguments:

```svelte
<script>
  import { createRawSnippet } from 'svelte';
  import MyGraphic from './ai2svelte/my-graphic.svelte';

  import { assets } from '$app/paths';

  function videoSnippet(src) {
    return createRawSnippet(() => ({
      render() {
        return `<video style="width: 100%; height: 100%; object-fit: cover;" src="${src}" autoplay muted playsinline loop></video>`;
      },
    }));
  }
</script>

<MyGraphic
  assetsPath={assets}
  videoA={videoSnippet(`${assets}/videos/videoA.mp4`)}
  videoB={videoSnippet(`${assets}/videos/videoB.mp4`)}
  videoC={videoSnippet(`${assets}/videos/videoC.mp4`)}
/>
```
