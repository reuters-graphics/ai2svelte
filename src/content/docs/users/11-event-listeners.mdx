ai2svelte components fire events you can listen to, so you can run your own code when the component mounts or its active artboard changes.

### onAiMounted

Fires once the component has fully rendered. Use it to start anything that needs the graphic to be on the page, such as third-party integrations or extra interactivity.

```svelte
<script>
	function handleAiMounted() {
	  console.log("ai2svelte component has been mounted");
	}
</script>

<MyComponent assetsPath={assets || '/'} onAiMounted={handleAiMounted} />
```

### onArtboardChange

Fires whenever the active artboard changes. ai2svelte uses container queries, so every artboard is in the DOM from the start. Use this event when you need to find elements in the artboard that's currently showing, for example when the same selector appears in every artboard.

```svelte
<script>
	function handleArtboardChange(artboard) {
	  // artboard is the newly active artboard element
	  console.log("Active artboard has changed:", artboard);

	  // find elements inside the active artboard
	  const POIs = artboard.querySelector(".PointOfInterest");
	}
</script>

<MyComponent assetsPath={assets || '/'} onArtboardChange={handleArtboardChange} />
```
