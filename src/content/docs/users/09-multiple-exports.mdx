ai2svelte can export several Svelte components from a single Illustrator document. This is useful for scrollers, or when you want to split a large design into separate components.

End the names of the layers you want to split out with a sequence number (for example `map1`, `map2`, `map3`). Each numbered layer is exported to its own component, together with every layer that has no number.

Then set `project_name` in your ai2svelte settings, using a `{start_number,number_of_layers}` placeholder where the number should go. For example, `project_name: map{1,3}layer` exports three files: `map1layer.svelte`, `map2layer.svelte` and `map3layer.svelte`.

<Aside type="tip">
  Layer order and the rest of the layer name don't matter, only the number at
  the end. Several layers can share a number; they all go into the same
  exported file.
</Aside>
