A tagged layer is a layer that ai2svelte exports differently from the rest of your artwork.

To tag a layer, add the tag to the end of its name in Illustrator. For example, name a layer `layer_name:svg` to export it as SVG.

---

### :div

Rectangles and circles in a `:div` layer become `<div>` elements that scale with the graphic.

### :symbol

Rectangles and circles in a `:symbol` layer become `<div>` elements that keep their original size and position when the graphic resizes.

### :png

The contents of a `:png` layer are exported as a PNG and placed in the output as a separate `<img>` tag. Use it for parts of your artwork that should stay raster.

Use `:png24` instead for higher color depth.

:::note
A `:png`/`:png24` layer is rasterized together with everything inside it. For predictable blend modes, apply the blend mode to the tagged layer itself rather than to its children.
:::

### :svg

The contents of an `:svg` layer are exported as SVG, so they stay sharp at any size.

<Aside type="note">
By default, the SVG is loaded through an `<img>` tag. To put the SVG markup directly in the component, enable the `inline_svg` setting.
</Aside>

:::note
Illustrator and browsers handle blend modes stacked between a parent and its children differently, so results in `:svg` layers can differ.

For consistent results, leave the parent layer on Normal and apply blend modes to the child elements.
:::

### :text

`:text` layers let you set their text from code through the `taggedText` prop. `taggedText` is an object with two keys, `text` and `htext`. Under each, add a key for every tagged layer (its name without the tag), and inside that, one key-value pair per text object in the layer.

### :htext

`:htext` layers work like `:text` layers, but the text is rendered as HTML through Svelte's `{@html}` tag, so it can include markup and formatting.

<Aside type="note">
  Set `override_text: true` to always take the text of `:text` and `:htext`
  layers from the `taggedText` prop, ignoring the text in the Illustrator
  document.
</Aside>

<Aside type="tip">
  The generated Svelte file ends with a comment showing a rough `taggedText`
  object for your layers. Use it as a starting point.
</Aside>

### Artboard tags

You can also add directives to artboard names to control how each artboard is exported.

For example, naming an artboard `Artboard1:600,fixed` makes it `fixed`-width and shows it only when the viewport is at least 600 pixels wide.

Naming an artboard `Artboard2:image_only` exports only its images, leaving out text and other elements.
