Illustrator and CSS name fonts differently, so ai2svelte needs to know which CSS font stack to use for each custom font in your design. You set this up once in the font configuration.

---

### Getting started

The first time you export a document that uses custom fonts, ai2svelte:

- Tells you which fonts have no mapping
- Lists every font it found in the document
- Asks you to add the missing mappings

### Adding font mappings

{/* prettier-ignore */}
<Steps>
  1. Open the `Settings` tab in the ai2svelte panel.
  2. Find the `Font Configuration` section.
  3. Add one mapping per line, in this format:
</Steps>

```yaml
Knowledge2017: 'Knowledge', Arial, sans-serif
AdobeFontName: 'CSS Font Name', fallback1, fallback2
```

### How it works

- **Saved between sessions**: mappings are stored and applied to every future export
- **Fallbacks**: list as many fallback fonts as you need
- **Editable**: change a mapping at any time

### Best practices

- Always end with web-safe fallbacks (Arial, Helvetica, sans-serif and so on)
- Put quotes around font names that contain spaces
- Check your font stacks in different browsers and operating systems
