You can style your artwork from the `Styles` tab of the panel, without editing the generated component by hand.

The tab comes with a set of preset CSS shadows and animations that you can apply to any element in one click.

---

### Shadows

The preset shadows come from Luis Sevillano's [cheesy-shadow-picker](https://luissevillano.net/cheesy-shadow-picker/).

To apply one, type a CSS selector into the `Identifier` field, then click a shadow card. If you [set up AiHostAdapter](../auto-detect/), the selector fills in automatically when you select an object in Illustrator. The shadow's CSS is added to the exported file.

<Image
  class="plugin-image"
  src={Image_Shadows_UI}
  alt="Screenshot showing UI for shadow selection"
/>

The floating toolbar at the bottom lets you change the preview: swap the backdrop behind the cards, pick a different typeface and weight, and change the text fill and shadow colors.

<Image
  class="plugin-image"
  src={Image_Shadows_Extra}
  alt="Screenshot showing extra shadow options"
/>

You can also use part of your screen as the backdrop. Click `Capture backdrop`, then drag across the area you want to capture.

:::note
Screen capture needs permission. On macOS, open **System Settings > Privacy & Security > Screen & System Audio Recording** and turn on Adobe Illustrator.

Screen capture isn't available on Windows yet. Contributions to improve Windows support are welcome.
:::

The backdrop, typeface and text fill color are for previewing only. They don't change the exported CSS.

### Animations

The `Styles` tab also has preset animations that you apply the same way.

<Image
  class="plugin-image"
  src={Image_Animations_UI}
  alt="Screenshot showing UI for animation selection"
/>

<Aside type="tip">
  You can apply several shadows or animations to one selector. If two
  animations conflict, the one defined last wins.
</Aside>

### Advanced styling

Switch the view from `UI` to `Code` to write SCSS directly.

<Image
  class="plugin-image"
  src={Image_Shadows_Code}
  alt="Screenshot showing code editor for advanced styling"
/>

Each shadow is a mixin that takes a color argument. Animation mixins take their own arguments, which you can change to customize the animation.

  class="plugin-image"
  src={Image_Animations_Code}
