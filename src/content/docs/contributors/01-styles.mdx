### Shadows

The preset shadows are defined in [shadows.json](https://github.com/reuters-graphics/ai2svelte/blob/main/ai2svelte/src/js/main/Tabs/data/shadows.json). Edit this file to add your own.

Each shadow is a JSON object with two required properties:

- `shadow`: a CSS `text-shadow` declaration. Write every color as `rgba(0, 0, 0, a)`, black with varying alpha.
- `id`: the name shown in the `Styles` tab. It must be unique.

```json
{
  "source": "https://example.com/",
  "shadow": "text-shadow: 0 1px 2px rgba(0, 0, 0, 0.6), 0 0 2px rgba(0, 0, 0, 0.3);",
  "id": "Parmesan"
}
```

Then run `pnpm bake-shadows` from the `ai2svelte/` folder. It converts the rgba values to hex and writes `shadowsBaked.json`, which is the file the `Styles` tab reads.

### Animations

The preset animations are defined in [animations.json](https://github.com/reuters-graphics/ai2svelte/blob/main/ai2svelte/src/js/main/Tabs/data/animations.json).

Each animation is a JSON object with `name`, `usage`, `arguments`, `animationRule`, `definition` and `candidate` properties. `name` is the animation's name, and `definition` holds its CSS keyframes. `candidate` sets the kind of element the animation is for: `"shape"`, `"text"` or `"line"` (an SVG path).

```json
{
  "name": "pulse",
  "usage": "@include animation-pulse()",
  "arguments": "($scale: 0.8)",
  "cssVariables": {
    "--scale": "#{$scale}"
  },
  "animationRule": "pulse 1s ease-in-out 0s infinite",
  "definition": "@keyframes pulse { 0%, 100% { transform: scale(1); } 50% { transform: scale(var(--scale)); } }",
  "candidate": "shape"
}
```

<Aside type="tip">
  In keyframes, prefer the individual transform properties (`translate`,
  `scale`, `rotate`) over a combined `transform: translate(...)`. That way an
  animation won't accidentally override transforms set by classes or inline
  styles.
</Aside>

To add an animation, follow the same structure and give it a unique `name`. It appears in the `Styles` tab once you save `animations.json`.
