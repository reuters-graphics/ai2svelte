### Frontend tests

The Svelte panel UI (`src/js/`) has a Vitest suite. Run these from `ai2svelte/`:

```bash
pnpm test        # run once
pnpm test:watch  # watch mode
pnpm test:ui     # Vitest UI
```

<Aside type="note">
  The ExtendScript conversion engine (`src/jsx/`) has no unit tests. It runs
  inside Illustrator's scripting engine, not Node, so check it with the visual
  regression suite below or by hand in Illustrator.
</Aside>

### Visual regression tests

```bash
pnpm test:visual
```

This catches unintended changes to the `ai2svelte.js` conversion engine. It only runs **locally**: you need Illustrator installed and a prior `pnpm build` (for `dist/cep/jsx/index.js`). It doesn't run in CI, which has no licensed copy of Illustrator.

The test drives a real copy of Illustrator through `osascript`/`do javascript`. It runs the real export path on the fixture `.ai` files listed in `scripts/visual-test/fixtures.json` and bundles the generated `.svelte` output. Playwright then compares screenshots of it with the committed baselines in `scripts/visual-test/__screenshots__/`. A separate Vitest snapshot test compares the generated `.svelte` text itself, which catches logic changes a pixel diff might miss.

To add a fixture, add an entry to `fixtures.json` with a name, an `.ai` file path and, optionally, a `settings` override. For example, `{ "image_format": "svg" }` tests the SVG export path on the same artboard.

The baselines are the last approved output, not a fixed standard. When a change is intentional, regenerate the output and review the diff before you accept it:

```bash
pnpm test:visual:generate            # re-run the real Illustrator export
playwright test --update-snapshots   # accept new screenshots
vitest run src/js/main/__tests__/ai2svelte-output.test.ts -u  # accept new .svelte snapshot
```
