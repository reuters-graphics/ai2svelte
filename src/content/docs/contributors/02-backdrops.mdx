The backdrop images behind the shadow preview cards in the `Styles` tab live in the [backdrops](https://github.com/reuters-graphics/ai2svelte/tree/main/ai2svelte/src/js/assets/images/backdrops) folder. Add or replace images there to change the backdrops available for testing shadows.

Keep images at about 320×180 pixels to keep file sizes small.

Order backdrops by how easy text is to read on them, from high contrast (easy) to low contrast (hard). The first backdrop is the default when the `Styles` tab opens.

Name each file `backdrop_<number>.jpg`, where `<number>` is the next unused number in the sequence. After adding backdrops, update `maxBackdropCount` in [ExtraConfigs.svelte](https://github.com/reuters-graphics/ai2svelte/blob/main/ai2svelte/src/js/main/Tabs/Styles/ExtraConfigs.svelte) to the new total.
